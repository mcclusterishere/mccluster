# HERE Precision Chrome v2

Asset 5 of HERE Material System 2.0.

This is the restraint material.

Chrome exists only to make the existing HERE interface feel precision-machined: tiny
bevels, button/control rims, icon hardware, hairline separators and brief grazing-light
catches.

If a user looks at a screen and says "wow, that's a lot of chrome," it has been used
incorrectly.

## Pairing

Obsidian Surface = deep structural world
Blackened Steel = dark physical chassis
Ruby Glass = semantic active energy
Smoked Glass = optical floating layer
Precision Chrome = microscopic reflected-light detail

The environment/light should make the chrome appear and disappear naturally as the
viewing relationship changes.

2048×2048 seamless/tileable.
