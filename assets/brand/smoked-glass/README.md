# HERE Smoked Glass v1

Asset 4 of HERE Material System 2.0.

This fills a gap in the original material set: a real optical surface for the HERE app's
existing sticky headers, mini-player, floating controls, modal/sheet overlays and other
UI that already sits above photography, video or 360 content.

It is deliberately NOT a glassmorphism system.

The glass stays dark, neutral and nearly invisible until reflections or content behind it
reveal its optical character. It should help the existing media remain dominant while
giving floating UI physical depth.

## Important pairing

- Blackened Steel v2 = structural chassis
- Smoked Glass v1 = optical layer over existing floating UI
- Ruby Glass v2 = semantic active energy
- Obsidian Surface v2 = deep structural/page material

Do not invent new cards simply to show this material.

2048×2048 seamless/tileable.
