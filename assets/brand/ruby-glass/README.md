# HERE Ruby Glass v2

Production Ruby material for the current McCluster / HERE reskin.

This replaces flat red accents with a deep, refractive optical material while preserving
the current interface and its semantic meaning.

## Use it for

- active navigation states
- playback/progress
- selected controls
- sound/connection/status indicators
- existing ruby/red lines
- restrained transition energy

## Do not use it for

- full red cards
- giant glowing backgrounds
- tinting photography or video
- adding red decoration where the current design does not already need emphasis

## v2 improvements

- deeper, darker ruby
- transmission + thickness channels
- facet/fresnel response
- caustic and flare masks for tiny optical moments
- separate active/emissive masks
- selector mapping to the actual HERE app
- CSS fallback + shader contract

The goal is for red to feel like embedded ruby glass carrying energy inside the current
interface, not neon CSS.

2048×2048 seamless/tileable.
