# PRIM3 asset kits

| Kit | Source | Use |
|---|---|---|
| `white-industrial/` | Supplied by the owner on 2026-11-02 (made with ChatGPT): 24 original procedural GLBs, generated by `generate_assets.py` (Python standard library only), 12,104 triangles total, catalog with footprints, cover, walkable surfaces and traversal heights. | The level builder's palette (`catalog.json`), and the Transit / Relay renderer (`js/prim3-tactics/level3d.mjs`), which fits kit models over the containers, barriers, crates, rooftop units, trees and relay. |

The renderer fits each kit model to the footprint and height of the object it replaces. The level's own data (blockers, cover, heights) stays the rule source; a kit model never changes a rule. If the kit cannot load, the procedural stand-ins remain.
