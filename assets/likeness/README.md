# Likeness source — Matthew McCluster

Reference photographs supplied by the owner for building his low-poly
avatar in the Uprise World. Five angles:

| file | angle | note |
|---|---|---|
| mcc-front-portrait.jpg | front, slight 3/4 | 1373x1469 — the primary face reference |
| mcc-profile-left.jpg    | left profile      | 1699x1763 — clean silhouette, jaw and nose |
| mcc-top-down.jpg        | top-down          | 1507x1764 — hair part and crown, for the twists |
| mcc-rotated-3q.jpg     | three-quarter     | 3088x2316 — SIDEWAYS, rotate 90 deg before use |
| mcc-body-jet.jpg       | full body         | 740x628 — proportions, stance, clothing only |

The defining features to carry into the model: shoulder-length two-strand
twists, full beard, and the build read from the full-body frame. The
avatar is low-poly and cel-shaded by design — the goal is recognisably
him at a glance, not photoreal.
