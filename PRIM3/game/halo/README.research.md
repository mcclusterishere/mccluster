# Current Source Findings

The PRIM3 Library already contains canonized Site 0 records. Current asset metadata identifies Site 0 Master Facility v02 as canon version 2.0.0 and defines the facility stack from L4 through B5, including Planetary Freight & Interfacility Transit Nexus at B4 and Supreme Habitat & Coordination Node at B5. The Library also contains game/visual derivative records for HITMAN ASIMOV and HITMAN PRIM1.

These records support the existence of a rich Site 0/home-base canon and reusable visual assets, but they do not by themselves establish the current full human character roster or each character's country/jurisdiction relationship.

Country mapping therefore remains intentionally unset until a roster-specific authoritative source is located and reconciled.
