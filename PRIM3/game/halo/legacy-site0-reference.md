# Legacy Site 0 Game Reference

The existing `_unfinished/site0-game/` directory remains reference material while PRIM3 Halo is rebuilt under the canonical `PRIM3/game/halo/` namespace.

Preserve its useful design precedent: it labels scenarios as fictional and avoids language that could falsely imply real government credentials, live government operations, active clearance, or real authority.

Before harvesting any legacy asset or component:

1. verify provenance/license;
2. classify it as reusable engine/UI, Site 0 canon asset, or obsolete build output;
3. move/copy only source assets needed by the canonical game;
4. do not import real Halo Ops datasets or credentials;
5. keep any government-styled fiction unmistakably fictional.

The long-term goal is not to run the `_unfinished` build in production. It is to salvage reviewed primitives into the canonical game runtime and retire duplicate/obsolete build artifacts deliberately.
