# Geography and Source Policy

Broad real-world geography is a grounding layer, not a claim that fictional operations occurred there.

Use authoritative public sources for country/region/city names, physical geography, climate, language context, and non-sensitive architectural/ecological references. Record source URLs/refs in research artifacts before a location becomes canon.

Do not copy proprietary game maps, mission text, UI assets, or code. Strategic-globe mechanics may be informed by genre conventions, but PRIM3 presentation and content must be original.
