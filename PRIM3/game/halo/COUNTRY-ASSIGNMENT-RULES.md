# Country Assignment Rules

The 21 core countries must be selected as a campaign set, not one mission at a time.

## Hard constraints

- one country per core arc;
- three distinct broad regions/sites inside that country;
- fictional mission facilities only;
- no inferred character nationality/jurisdiction;
- no live operational data dependency;
- no exact sensitive real facility as a target;
- every assignment carries canon/source references.

## Campaign-level balance

The final 21-country set should avoid accidental over-concentration in one continent unless the character/curriculum canon requires it. Optimize for meaningful global spread, distinct physical environments, distinct urban/rural/infrastructure contexts, and representation already present in the character pool.

## Assignment score

For each candidate core-country pair record a 0–5 score for:

- character/jurisdiction canon fit;
- curriculum/learning fit;
- narrative fit;
- availability of three distinct regions;
- environmental/architectural distinctiveness;
- campaign geographic balance.

Also record blockers and source confidence. The highest numeric score is not automatically canon; scores make the editorial decision auditable.
