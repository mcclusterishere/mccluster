# Pilot specification (before fitting any observations)

One fixed northern fall/early winter window: UTC weeks starting 2019-10-14 through 2020-01-06. In each week take the chronologically first 22–26 hour SAR pair whose endpoints both fall in that week. No substitution based on measured ice behavior. Each scene pair represents one sampled day, **not a weekly mean**.

* On the source EPSG:3413 grid, classify each pair using a disjoint western (smaller projected x) portion at nominal 1.4 km. The eastern portion supplies target values at 2.8, 5.6 and 11.2 projected km. Use an 11.2 km buffer, centered at the midrange of valid columns; do not classify from an eastern target pixel. This is an observed concomitant, not an independent driver or forecast. Compare with reversed sides.
* Average all four signed derivative components over each nonoverlapping square before computing divergence, shear and total deformation; then area-weight the resulting positive norms. Require shared spatial support across all three scales by retaining 16×16-cell tiles where each 4×4 sub-block passes coverage. Retain at least four tiles per region. Primary: ≥ 75% valid pixels per 4×4 target sub-block, ≥ 75% valid per 2×2 in the classifier. Sensitivities: 100%, shift grid eight cells, swap sides. Accept finite source shape/reliability/latitude and all four derivatives; do not invent a texture-flag cutoff or positional precision.
* Use nominal projected lengths for the primary estimator; report ground-length range using the WGS84 EPSG:3413 local scale factor at observed latitudes. No sub-kilometer results; these are window sizes, not instrument resolving powers.
* Train on all *other* weeks, including no week within 7 days (exclude the immediate neighbors too), no shared acquisitions or interval overlap. The median western activity in training alone splits lower/higher activity. Fit equal-weight scene-scale summaries with OLS on natural logarithms. Compare M0 pooled intercept and slope, M1 group intercepts/shared slope, M2 group intercepts/separate slopes. Condition on an observed label at test time. Equal-weight held-out weeks, not pixel-level samples. Report mean held-out squared log error (MSLE), per-week counts and losses, fit slopes, median absolute shape error using a 5.6 km pivot as a descriptive diagnostic. Do not treat spatial tiles or folds with overlapping training data as independent.
* No robust evidence for an interaction if improvement in M2 over M1 is negligible or inconsistent in the sensitivity runs. This is exploratory: no selected winner, calibrated measurement uncertainties, confirmatory p-values, global inference or novelty assertion.

Input compatibility amendment before the first model fit: six of the thirteen selected files omit the optional valid_shape variable. Require finite gradients, latitude and texture indicator throughout; where the shape mask exists, also require it to be finite. Record its presence for each file. No changes to selection, models or folds.
