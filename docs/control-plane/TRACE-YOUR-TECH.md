# Trace Your Tech — draft pilot

Entry: the Equity Uprise feed tab on the existing World, directly below the Environmental Justice panel. The preview requires no login and sends no device identifier. It uses the existing same-origin Globe focus message on user click, with country-level example coordinates and no shipment lines. No change to the shared dock, environment data gate, or owner Halo.

| Capability | Pilot | Remaining |
| --- | --- | --- |
| Interactive map and country/material stories | Existing globe focus and dated editorial cards | Dedicated markers and linked map-to-story selection |
| Environmental, human and geopolitical lenses | Filterable Environment, People and Power & trade | More cross-lens coverage beyond cobalt and lithium |
| Material library | Two battery material entries | Other components, more materials, broader stages |
| Sources and clear claims | Source library by selected filters, individual source links and claim classes | Source health, correction workflow and editorial review |
| Media | No copied images, footage, or other assets | Licensed or original media and transcript/accessibility checks |
| Timeline | Dated reporting, policy and manufacturer disclosure records | Ongoing publisher and agency ingestion; no live coverage claim |
| Take action | Repair, reuse, recycle guidance; visit-only next step selection | Real mission registration, assignments and evidence through existing Action Network |
| User's exact device | Explicitly unknown. Model disclosure is separately marked | Model lookup grounded in manufacturer documents; exact-unit provenance only with verified chain of custody |

This branch is a review preview, not a release. Do not add a second mission store. An approved canonical Action Network mission must have a real ID and use the existing join/proof flow before displaying server-backed completion, credits or progress. Owner approval and a real hosted 390px and signed-in/non-owner check are prerequisites to release. The public [Mine My Phone](https://www.backmarket.com/en-us/mine-my-phone) is the feature reference, not an asset, code, or text source for the implementation.
