# Uprise World Visual References

This directory contains the canonical visual source files for Uprise World. `../REFERENCE-MANIFEST.md` is the controlling index and authority document.

---

## ⛔ READ FIRST — the style board is NOT a character reference ⛔

`style/living-sketch-style-reference-board.jpg` shows drawings of a person.
**That person is not Matthew McCluster, is not the protagonist, and is not any
character in Uprise World.**

Those figures are anonymous stand-in bodies used to demonstrate **ink, graphite,
wash, and paper technique only**. Take rendering technique from that board. Take
**nothing** about face, hair, skin tone, beard, build, age, clothing, or identity
from it — not for the main character, and not for any NPC.

The **STYLE 01** and **STYLE 02** panels inside
`boards/canonical-visual-reference-board.jpg` are the same drawings and carry the
same restriction.

Full rules: **`style/README.md`**. Read it before using anything in `style/`.

## Non-negotiable clothing placement

- Kingdom Stepper: front chest of washed-blue hoodie.
- HM + vertical AMMO bullet + halo: large centered back of hoodie; no extra artifacts.
- WARROOM sword: one sleeve.
- SEEK FIRST with drone above: opposite sleeve.
- 33 target: lower front hoodie and front of joggers.

Garment placement comes from the wardrobe board and the exact emblem files. It
never comes from the style board — the jacket and tee drawn there are not
canonical wardrobe.

Exact standalone emblem files outrank composite boards and prose. Do not redraw or regenerate them.

## Known-bad files

Two canonical PNGs in this directory are **truncated and contain no usable image
data**. They must be re-supplied from the owner's originals, and must never be
regenerated, redrawn, or approximated:

- `character/mccluster-character-likeness-sheet-approved.png` — 7,506 bytes; `IHDR` + truncated `caBX`, zero `IDAT`, no `IEND`.
- `emblems/kingdom-stepper-approved.png` — `IDAT` stops at 16,384 bytes, no `IEND`.

Until they are replaced, protagonist likeness comes from `assets/likeness/` and
the character panels of the composite and Proof Room boards — **never** from the
style board.
