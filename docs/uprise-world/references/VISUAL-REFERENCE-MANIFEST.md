# Uprise World — Visual Reference Manifest

The canonical manifest is `../REFERENCE-MANIFEST.md`.

Use that file as the single source of truth for the exact McCluster likeness reference, canonical wardrobe, all exact emblem files and garment placements, Living Sketch style board, Proof Room concept board, and screenshot acceptance rules.

If anything in older documentation conflicts with `../REFERENCE-MANIFEST.md`, the canonical manifest wins. Do not regenerate or reinterpret an exact emblem when its approved source file exists under `references/emblems/`.

## ⛔ The Living Sketch style board is NOT a character reference ⛔

`style/living-sketch-style-reference-board.jpg` draws a person who is **not
McCluster, not the protagonist, and not any character in Uprise World**. It is
authoritative for **rendering technique only** — ink, graphite, wash, paper. It
is authoritative for **nothing** about face, hair, skin tone, beard, build, age,
clothing, or identity, for the main character or for any NPC. The **STYLE 01**
and **STYLE 02** panels of the composite board carry the same restriction. See
`style/README.md`.
