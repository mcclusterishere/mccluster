## Source contract

Use frame captures from the actual Computer Workbench and the existing Server Lab, not generated images as geometry authority. Record canonical asset ID, profile ID, mode and the exported equipment evidence. A workstation reference is generic teaching equipment; it is not a photographed installed vendor machine. No video may turn a provisional hardware layout into an as-built claim.

Make a 30-second, four-shot pilot. Capture the workstation at Front, Inside, Rear / ports and Exploded. Use the complete uncropped source frame. Keep component counts, sockets, ports, cables, orientation and chassis proportions fixed. Generated camera motion may explain a view; it must not create a different motherboard or invent a wiring path. Add verified labels and captions in editing rather than relying on generated text.
