# Equity Uprise HQ redesign | Blender concept set
Seven furnished north-up overlays on the Core V2 source plans. The GPT Image boards guide atmosphere, materials and equipment; use the plans, not the images, for geometry. Nothing here certifies actual construction, egress, access or rooftop operations.

## Stack
72 × 72 ft footprint (21.9456 m square), 18 ft grid, southwest origin, +X east, +Y north, +Z up. F1–F7 elevations in feet: 0, 13.5, 27, 40.5, 54, 67.5, 81. B1 at -13.5 is unchanged. Convert feet to meters once using 0.3048. Reuse one core. Passenger lift X54–62/Y34–44 (west-facing, assumed service F1–6); freight X0–8/Y60–72 (south-facing); stair B X8–18/Y54–72, stair A X60–72/Y54–72, with south doors at Y54; riser X50–60/Y66–72. Keep north circulation Y54–60 and both stair approaches clear. The only normal public entrance is centered on the south facade at F1. Use the source F1 site-egress model for separate exit-only discharge. F2–F6 have sealed south glazing. F7 is an open roof with two stair headhouses and no assumed operational elevator stop. The mobility zone is a digital staging reservation, not an approved helipad. Keep plant access, roof edges and door swings clear.

## Blender workflow
Duplicate the combined Core V2 scene or start a new set file. Preserve the source shell and import only furniture into that model. Link repeated WORKPOINT, LOUNGE_BANQUETTE, CONSULT_TABLE, ARCHIVE_CABINET and CHECKIN_KIOSK kit assets across levels instead of duplicating meshes. Match colored markers on each SVG to 52 CSV rows. X/Y are editable center locations and dimensions are proxy envelopes, not vendor measurements. Own the object placement and clearance pass in the real scene; these are not door-swing or code checks. Materials: pale concrete and blackened steel throughout; oak F1, terracotta F2, teal F3, walnut and burgundy felt F4, olive/gray F5, smoked glass and dark stone F6, galvanized steel F7. Check walkability and 1.65 m camera passes before dressing. Keep roof signage destination-agnostic, and one suspended Halo Globe on F6 at X55/Y12 ft, 4.5 ft diameter and center 8.25 ft above the floor. The concept image shows a pedestal; do not build it. The executive suite in the pilot is story staging on F6 adjacent to Executive Command, not a new floor or a change to these shell plans. Use upper floors' studio/workspaces according to canon, not invented departments.

To lay out wire boxes without saving or touching the shell: `blender --background existing.blend --python place-asset-proxies.py -- asset-map.csv`. Pass absolute paths if not in the same directory. The setup script targets meter-based models, adds a clearly named collection and does not save. For visual editing run from the Scripting workspace and set ASSET_MAP to the absolute path if needed. Existing .blend files were not changed.
