From the historical roof / ecosystem concept:

- open-air rooftop identity;

- modest city overlook;
- restrained dark mineral / gunmetal / exterior architectural language;

## Correct / upgrade

Historical or chassis-only roof work is upgraded as follows:

- generic roof slab → detailed walkable roof plane with real shared openings;
- stairs that only visually terminate at the roof → **human-walkable Floor 6 → Level 7 transitions with open roof doors**;
- continuous stair-enclosure south walls that could visually seal the stair → level-by-level south-wall openings using Core V2 access-opening coordinates;
- roof chassis placeholder → inventory-backed detailed 3D environment;
- generic roof-access notion → two explicit protected stair headhouses plus passenger overrun/service treatment;
- empty service band → screened plausible rooftop mechanical/MEP equipment;
- abstract routing zone → restrained Ecosystem Routing Beacon;
- mobility reservation → non-regulatory field/ring, explicitly not an approved helipad;
- bare edge → guarded overlook, minimal seating, low-level path lighting and roof-support details;
- generic Level 7 route → explicit optional Uprise World route node that remains secondary and experimental.

- no obsolete Core V1 stair/service-core coordinates;

- no fixed-wing runway;
- no certified helipad/TLOF/FATO markings;
- no rooftop nightclub, bar, pool or large garden;
- no fleet of decorative aircraft;
- no giant tactical/sci-fi routing wall;
- no hard-coded map of every McCluster website;
- no Uprise World visual language taking over Equity Uprise architecture.

**Historical roof intent + proven stacked-building geometry + current Core V2 stair/core truth + reconciled three-capability Level 7 program + inventory-backed real 3D = final Level 7 review build.**
