## 1. Owner intent

Level 7 is the rooftop layer that connects the Equity Uprise website to the wider website ecosystem.

The canonical experience is:

1. the user moves upward from Floor 6;
2. the user arrives on the Equity Uprise roof;
3. the roof reveals the surrounding city/context;
4. the user can choose another ecosystem destination;
5. a helicopter / vertical-lift travel metaphor represents departure;
6. the transition carries the user to another website represented as another building/place;
7. compatible destinations may use the same roof/arrival metaphor for return travel.

This means Level 7 is not merely a scenic roof.

It is the **canonical ecosystem departure and arrival plane**.

The ecosystem itself is **not spatially mapped into the roof plan**. Destination data is dynamic and lives outside the architectural geometry.

Read with:
- `FLOOR-07-ECOSYSTEM-ROUTING-CONTRACT.md`
- `FLOOR-07-SCHEMATIC-PLAN-BASIS.md`

## 11. Ecosystem-plane semantics

This section is architectural authority even though it is not physical geometry.

### Level 7 is the ecosystem layer

Future agents and implementations must understand:

- **Equity Uprise is one building/site in a larger network of website-buildings.**
- **Level 7 is where users leave or arrive between those websites.**
- The roof represents the ecosystem connection layer.
- The helicopter/vertical-lift travel metaphor is the canonical transition language unless later changed by the owner.
- The rooftop plan itself does not contain the full ecosystem map.
- Other websites may later define their own arrival/departure places.
- The same destination registry can power multiple sites.

### Architectural separation
Adding or removing a website destination must **not** require changing:
- roof footprint;
- core;
- mobility reservation;
- stair locations;
- service zones;
- overlook geometry.

The ecosystem is data; the roof is infrastructure.

- a specific roof arrival sequence;
