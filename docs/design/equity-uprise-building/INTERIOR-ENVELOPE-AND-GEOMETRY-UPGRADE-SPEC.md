# Equity Uprise — Interior Envelope + Geometry Upgrade Spec

> Status: **ACTIVE INTERIOR-BUILDOUT AUTHORITY — IMPLEMENTATION PENDING**
>
> This document governs geometric realism inside B1 and Floors 1–6 and coordinates the Level 7 roof-access/service condition.
>
> **Not for construction.**

## Intent

Upgrade each floor from a program/furniture scene into a believable built interior without reopening the approved floor program.

## Required architectural layers

Future detailed implementation should coordinate, where applicable:
- floor finish over structural/walking plane;
- partition thickness;
- wall returns and corners;
- framed door openings;
- door leaves / hardware implication;
- interior glazing + mullions;
- ceilings, soffits or deliberately exposed service ceilings;
- ceiling access panels;
- built-in millwork / storage;
- thresholds and transitions;
- acoustic treatment in media / meeting spaces;
- equipment/service alcoves;
- janitorial/support storage where needed;
- service corridors / back-of-house edges where compatible with program.

## Room-support rule

A programmed room must include the architectural support needed for its function.

Examples:
- media rooms: acoustic envelope, equipment support, power/data/AV endpoints;
- conference/command rooms: table power/data, display support, lighting control;
- research/work rooms: work power/data, storage, display support;
- lobby/public areas: wayfinding, security/communications, lighting and life-safety devices;
- technical spaces: panels, racks, trays, pipe/duct support and maintenance access.

## Device-level realism

Later geometry should include representative:
- receptacles / floor boxes where visible;
- data outlets / wall plates where relevant;
- light fixtures;
- diffusers / grilles;
- detectors / strobes / alarm devices;
- extinguishers/cabinets;
- access readers / intercoms in controlled zones;
- cameras where program/security logic warrants them;
- plumbing fixtures / drains / service sinks where program requires them.

The model does not need to reproduce every fastener or every branch circuit. It does need enough coordinated detail that systems do not appear magical.

## Ceiling rule

Each space must intentionally choose one of:
1. finished ceiling;
2. acoustic ceiling;
3. specialty/acoustic media ceiling;
4. exposed technical soffit;
5. open-air roof condition.

No floor may simply lack ceiling logic because it was not modeled yet.

## Support-space rule

If later systems coordination demonstrates a need for a small IDF, electrical closet, janitor closet, AV rack alcove or similar support element, it may be added only when:
- it does not move the shared core;
- it does not erase a canonical program space;
- it is documented in the appropriate floor services addendum;
- circulation remains viable.

## Interior/facade interface

Interior walls, ceilings and furniture must coordinate with exterior glazing.

Do not place:
- major opaque walls through the middle of a glazing bay without intent;
- furniture inside curtain-wall depth;
- screens/signage floating outside the envelope;
- ceiling planes that visually penetrate facade framing.

## Visual quality rule

Use geometry that catches light:
- modest edge bevels where renderer/tooling permits;
- reveals and joints;
- material thickness;
- trim/frame depth;
- shadow gaps where appropriate.

The goal is architectural legibility, not decorative clutter.
