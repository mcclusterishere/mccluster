# Equity Uprise — Workplace Occupancy Authority

> Status: **CANONICAL LIVING-WORKPLACE AUTHORITY v1.0**
>
> Scope: recurring named staff, workplace archetypes, floor identity and story/game occupancy.
>
> Equity Uprise HQ is the recurring workplace headquarters. It is **not Site 0 / Root HQ**, the separate hidden McCluster Corp / PRIM facility used by the final RAID story.

## Building-life rule

The building is an inhabited workplace, not an empty training shell.

Every floor carries:
- named recurring PRIM3 cast workspaces;
- recurring role/archetype populations;
- ordinary work before missions begin;
- persistent desks, benches, offices and support stations;
- consequences when people transfer, die, get promoted or leave.

The canonical machine-readable roster is:

production/workplace-occupancy-v1.json

The corresponding story authority lives in the PRIM3 repository:

story/EQUITY-UPRISE-WORKPLACE-CANON.md

The two files must remain semantically synchronized.

## B1

B1 is **Technical Operations + Infrastructure + Security + Hands-On Lab**.

It is a known, staffed floor.

It is not a secret owner-only level.

General work areas, the systems lab, workshop, telecom operations, security station and tunnel-operations concourse can be used by authorized staff and supervised learners/instructors.

Hazardous electrical, fire/water, plant, transfer-lock and other controlled compartments retain room-level safety/access restrictions.

The tunnel network is known operational/logistics infrastructure. Knowledge that it exists is not a secret. Specific operational sectors may still be controlled for safety and security.

## Population rule

Future human/NPC generation should use:
1. named recurring characters first;
2. the floor archetypes in workplace-occupancy-v1.json;
3. additional background workers only when a real operational role requires them.

Do not populate the building with generic anonymous bodies that ignore the existing PRIM3 roster.

## Visual continuity rule

A workspace can accumulate personal items, wear, changed equipment, photographs, notes, evidence and relationship residue.

A vacancy is visible.

If a recurring worker dies, transfers or leaves, their space should not instantly reset.

> **If you die, the building changes.**

## Game rule

Later PRIM3 assault/defense gameplay should consume this building and occupancy state rather than invent a separate workplace map.

Equity Uprise is home.

Site 0 is the root succession conflict.
