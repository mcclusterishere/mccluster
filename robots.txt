# ============================================================
# AI CRAWLERS
#
# THE POLICY TODAY IS: READ IT.
#
# That is deliberate, and it is worth writing down because the obvious
# move right now looks like the opposite one.
#
# Blocking training crawlers only pays if something collects on the other
# side of the block. Cloudflare's pay-per-crawl turns a refusal into an
# HTTP 402 and a checkout at the edge — but that runs at the EDGE, and
# this property is not behind Cloudflare. DNS still answers from the
# old nameservers. So a Disallow line here would buy exactly nothing
# today: no payment, no negotiation, just less reach for a directory
# whose entire purpose is being found by somebody who needs a fellowship.
#
# The right sequence is: be maximally legible now, be behind Cloudflare
# next, and only then decide what a crawl is worth. See
# docs/agent-web.md for the flip, which is a few lines and one dashboard
# setting once the DNS move in docs/cloudflare-cutover.md is done.
#
# The desks stay closed to everyone regardless.
# ============================================================
